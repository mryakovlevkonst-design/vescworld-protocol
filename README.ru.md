# Протокол Vesc world

Как подключить свой проект — дисплей, приложение, логгер — к
**[Vesc world](https://t.me/vescworldbot)**: поездки, GPS-треки, чёрные ящики,
драг и расходники в мини-приложении Telegram, с гаражом, рейтингом сообщества
и ссылками «поделиться».

Ни ключей API, ни сервера. Устройство выгружает файлы в **личного бота
владельца** в Telegram, а [@vescworldbot](https://t.me/vescworldbot) читает этот
чат по токену, который владелец ему отдал. Так работает дисплей MLTRA.

- **[PROTOCOL.md](PROTOCOL.md)** — весь контракт (на английском): закреп `vw:1`, индекс, пути, форматы файлов.
- **[examples/card/](examples/card/)** — поездка, трек, чёрный ящик, драг и расходники ровно так, как их пишет дисплей.
- **[tools/vw_upload.py](tools/vw_upload.py)** — готовый загрузчик (Python 3, без зависимостей).

## Попробовать

1. В [@BotFather](https://t.me/BotFather) создай бота (`/newbot`), скопируй токен.
2. Открой нового бота, нажми **Start**.
3. `python3 tools/vw_upload.py --token <ТОКЕН> --dir examples/card --id DEMO-000001 --fw 1.0.0`
4. Отправь этот же токен в [@vescworldbot](https://t.me/vescworldbot) с того же аккаунта и открой приложение.

Дальше пусть твоё устройство пишет такие же файлы (по-настоящему нужен только
файл поездки) и делает те же шаги — у себя в прошивке, в приложении или
вызывая скрипт.

Вопросы и новые поля — в issues.
